# 双层大纲模板

原则：**用户层说人话**（用户逐条确认用），机器层给脚本吃。两层同一文件，机器内容放 ```machine 围栏；check_text.py 只认围栏（无围栏时退回旧行为，兼容早期大纲格式）。

## 文件骨架

```markdown

> 事实源声明：本文件是唯一事实源，任何改动需用户重新确认。

## 页码规则
- 用户报页码 = 成品物理页序；与原稿页号可能错位（删除页后差 1）
- 对齐方式：从成品逐页提取 ≥20pt 标题对照本表，禁止推算

## 确认记录
- 2026-XX-XX 用户确认：分类标记全表、删除页 P37、意图句、风格样张

#### P01 封面
- **这页在说什么**：产品名称 + 一句话定位 + 日期
- **怎么处理**：排版我发挥
- **原稿的图**：直接用原稿图片 1 张（公司大楼照片）
- **需要你拍板的**：无

```machine
- 资产：img008 → p001_1
- 动作：封面纯原生重建；标题/副标题/日期按原稿文字，无页脚

## 用户语言词汇表（对用户说话必须用左列）

| 用户语言 | 内部术语 | 一句话解释 |
|---|---|---|
| 严格按原稿布局重画 | strict / 照画 | 分层、分块、连线的位置关系照原稿，文字一字不改 |
| 重画成可编辑图形 | redraw / 重绘 | 结构简单的图用形状重建，之后可二次编辑 |
| 直接用原稿图片 | bitmap / 继承 | 原图嵌入，清晰度与原稿一致 |
| 原样搬原稿图形 | xml / 组拷贝 | 既 100% 保真又保持可编辑的搬运 |
| 这页不要 | delete / 删除 | 整页移除 |
| 排版我发挥 | free / 自由发挥 | 内容和想表达的意思不变，版式重新设计 |

## 分组确认话术（降低用户负担）

- 自由发挥页（通常占大头）批量带过："P4/P5/P6…这 20 页是列表/总结类，我重新排版但内容一字不减，具体效果样张里看"
- 逐条确认只留三类：
  1. 照画页清单——每页一句意图句 + "照原稿画，对吗？"
  2. 存疑图清单——每图一句判断 + 依据（"这张图元素太多，我建议直接用原图，画出来反而失真，同意吗？"）
  3. 删除页清单——"P37 这页要删掉，对吗？"
- 确认问题尽量封闭式（对吗？/要不要删？），用户一个字能答
- 确认结果当场写进"确认记录"节

## 机器层解析契约（check_text.py 消费）

- 页头：`#### PNN 标题`；`##`/`###` 级标题关闭当前页（防文件尾部附录混进最后一页）
- 页内 ```machine 围栏中的 `-` 行 = 文本审计来源
- 页无围栏时退回旧行为：所有非标题行都算审计来源，自动跳过 `- **资产/动作/原标题**` 等加粗标签行
- 已删除页用 `--gone 37,46` 声明；成品物理页号 = 大纲页号 −（前面已删页数）
- `img123`、纯数字格（`4x3`）等资产代号自动跳过，不计入缺失
